# ITDEV-140: Programming with Java

### Milwaukee Area Technical College

My Java coursework from ITDEV-140 at MATC.

## Activities

**[CellPhone](CellPhone/)**

A simple class for storing cell-phone details.

**[MagicSquare](MagicSquare/)**

Checks whether a grid forms a magic square.

**[AreaCalculator](AreaCalculator/)**

Calculates the area of circles, rectangles, and cylinders.

**[MorseCode](MorseCode/)**

Converts text to Morse code.

**[EmployeeRecords](EmployeeRecords/)**

Stores employee details using inheritance.

**[BinaryFileArrays](BinaryFileArrays/)**

Writes and reads an array of numbers using a binary file.

**[PropertyTax](PropertyTax/)**

Calculates property tax.

**[DormAndMealPlan](DormAndMealPlan/)**

Calculates dorm and meal-plan costs in a window.

**[RecursiveMultiplication](RecursiveMultiplication/)**

Multiplies numbers using recursion.

**[RecursivePower](RecursivePower/)**

Calculates a number raised to a power using recursion.

**[CustomerRecords](CustomerRecords/)**

Stores customer details and mailing-list preferences.

**[PasswordVerifier](PasswordVerifier/)**

Checks whether a password meets the required rules.

**[AverageRainfall](AverageRainfall/)**

Calculates total and average rainfall.

**[RestaurantSelector](RestaurantSelector/)**

Suggests restaurants based on dietary preferences.

**[TestScoreAverage](TestScoreAverage/)**

Calculates an average score and letter grade.

**[WiFiTroubleshooter](WiFiTroubleshooter/)**

Guides the user through Wi-Fi troubleshooting steps.

**[CompoundInterest](CompoundInterest/)**

Calculates savings with compound interest.

**[FuelEconomy](FuelEconomy/)**

Calculates miles per gallon.

**[GrapevineSpacing](GrapevineSpacing/)**

Calculates how many grapevines fit in a row.

**[SalesPrediction](SalesPrediction/)**

Estimates a division’s share of sales.

**[SalesTax](SalesTax/)**

Calculates tax and the total purchase cost.

**[StringOperations](StringOperations/)**

Shows basic string operations using a city name.

**[StockProfit](StockProfit/)**

Calculates profit or loss from a stock sale.
